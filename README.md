## 📖 Descripción

Sistema de gestión de calzado aplicando herencia, polimorfismo y clases abstractas para modelar categorías de zapatos (`Casual`, `Deporte`, `Elegante`).

---

## 🎯 Objetivos y Conceptos Clave

- [x] Clase base abstracta `Zapato` y métodos abstractos (`obtenerCuidado()`)
- [x] Herencia en Java (`extends`) con especialización de atributos
- [x] Polimorfismo con listas heterogéneas (`ArrayList<Zapato>`)
- [x] Cálculo dinámico del valor total del inventario

---

## 🛠️ Tecnologías Utilizadas

- **Java 17+**
- **IntelliJ IDEA**

---

## 🚀 Cómo Ejecutar el Proyecto

```bash
# 1. Clonar el repositorio
git clone https://github.com/albertguiteras/tiendaZapatos.git

# 2. Acceder al directorio de fuentes
cd tiendaZapatos/src

# 3. Compilar los archivos Java
javac *.java

# 4. Ejecutar la clase principal
java Main
```
